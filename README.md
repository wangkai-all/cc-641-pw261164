# 补贴申请断点回归分析页

按固定评分门槛（断点回归，RDD）分析补贴申请：导入虚构申请的**原始评分、是否获补贴、后续产出**，
在门槛两侧分别做三角核加权的局部线性拟合，比较门槛处的两侧差距。

## 运行

无需构建，直接用浏览器打开 `index.html` 即可；或起本地服务：

```bash
python3 -m http.server 8641   # 然后访问 http://localhost:8641
```

## 测试

```bash
node tests/run-tests.js   # 核心逻辑：拟合、护栏、同分联动、诊断、CSV（39 项）
node tests/smoke-dom.js   # 页面冒烟：最小 DOM 垫片中真实运行全部脚本（28 项）
```

## 功能与对应的分析纪律

| 功能 | 纪律 |
|---|---|
| 主图：门槛附近散点 + 两侧局部线性拟合；拖动把手/滑块调整分析范围；可设置贴门槛排除带 | 范围与排除带对两侧**对称**生效，不能为某一侧单独挑最有利的范围 |
| 保留/排除只由「评分与门槛的距离」决定 | 评分相同的申请必然一起保留、一起排除（桶明细面板内有同分联动核对） |
| 打开页面先检查获补贴是否严格由门槛决定 | 发现例外时显示**执行偏差**面板与明细，结果改按「跨过门槛」的影响（ITT）解释，不沿用严格门槛解释 |
| 有效性护栏 | 缺少任意一侧样本、某侧评分没有变化、带宽过小（< 2 分）、排除带 ≥ 范围时，**不输出有限效果值**，只显示原因 |
| 数据诊断：评分桶人数直方图 + 原有属性（成立年限、员工数）表 | 启发式检出**门槛附近集中申报**与**属性不连续**并提示其削弱因果解释 |
| 点击桶（柱或表行） | 核对桶内申请明细与每条的拟合权重 |
| 敏感性图 | 两侧差距随分析范围变化的曲线（含 95% 置信带），拖动范围时联动 |
| 保存结果（localStorage）/ 导出 JSON | 每条结果带**观察范围与排除规则**及适用范围声明：局部估计，不能推广到所有申请 |

## 数据

- 内置虚构数据（可换随机种子重新生成、可下载 CSV），刻意包含三类问题用于演示诊断：
  执行偏差（10 例未按门槛发补贴）、门槛正上方集中申报、门槛下方附近申请成立年限略长。
- 导入 CSV：必需列 `score,treated,outcome`（支持中文别名：评分/原始评分、获补贴/是否获补贴、产出/后续产出），
  可选列 `id,years,employees,industry`。

## 方法说明

- 估计量：两侧分别拟合 `y ~ 1 + (score - cutoff)`（三角核加权最小二乘），取门槛处截距之差；HC1 稳健标准误。
- 第一阶段：同一框架估计「获补贴概率」在门槛处的跳跃。
- 属性连续性：同一框架估计原有属性在门槛处的跳跃，|t| ≥ 1.96 时提示。
- 集中申报：桶人数与相邻桶均值比较（泊松近似 z），|z| ≥ 2 时提示；均为启发式提示，非正式检验。
